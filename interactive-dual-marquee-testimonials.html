⚙ Mechanical Anatomy

How the Infinite Seamless Marquee Operates

Achieving flawless infinite translation without jitter requires precise array multiplication, stationary CSS masks, and GPU compositor offloading.

01

Stationary Mask Container

The outer wrapper remains static while applying a vertical linear gradient alpha mask (mask-image). This creates seamless edge fades at top and bottom without altering element geometry.

CSS Masking API
02

3x Array Triplication

Testimonials are repeated 3 times ([...items, ...items, ...items]). The CSS translation moves from 0% to exactly -66.666%, resetting imperceptibly for infinite flow.

Modulo Continuity Math
03

Dual Counter-Velocity

Column A translates upward while Column B translates downward. This counter-momentum provides dynamic visual equilibrium that guides the user's eye naturally down the section without inducing motion fatigue.

Symmetrical Parallax
04

GPU Compositor Only

Transforms are bound exclusively to transform: translateY() with will-change: transform. Zero recalculation of layout tree (top, height), guaranteeing a locked 60 FPS.
